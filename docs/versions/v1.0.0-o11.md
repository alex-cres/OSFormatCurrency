## Added

- `GetCurrencyFormattedByLocale` — formats a decimal value as a locale-aware currency string using the specified locale, with optional currency symbol override and native digit rendering.
- `GetLocales` — returns all .NET-supported locales with their currency formatting rules.
- `Locale` structure with 11 fields for currency formatting metadata.
