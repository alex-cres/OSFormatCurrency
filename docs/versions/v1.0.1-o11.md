## Added

- Chinese numeral support for `zh` locales — correct display beyond the 0–9 format using the Chinese unit system (〇一二三四五六七八九十百千).
- Chinese financial numeral variant (零壹贰叁肆伍陆柒捌玖拾佰仟).
- Chinese decimal point rendering (点).
- Test screen in sample app to test a single format.
