# v1.0.4 (O11)

**Released:** 2021-01-17  
**Forge:** https://www.outsystems.com/forge/component-overview/10096/format-currency  
**Platform:** OutSystems 11

---

## Fixed

- Chinese Extended and Financial numeral rendering bug for some numbers.

## Changed

- `GetDecimalFromLocaleDecimalString` now accepts currency symbols in the input string. Added a `Currency` input parameter — if provided, overrides the locale's default currency symbol for parsing. The decimal output is the same whether or not the currency symbol is present in the string.
