# v1.0.5 (O11)

**Released:** 2021-01-25  
**Forge:** https://www.outsystems.com/forge/component-overview/10096/format-currency  
**Platform:** OutSystems 11

---

## Changed

- Chinese decimal point numbers now use direct numerals 0–9 after the decimal point (instead of Chinese unit numerals for the fractional part).

## Added

- Zero rules implemented (similar to the [NumbersToNative](https://www.outsystems.com/forge/component-overview/10065/numberstonative) component).

## Known Issues (in this Forge version)

- `IsValidDecimal` not set to `false` on parsing error paths — always returns `true`.
- `ssCurrency.Equals("")` throws `NullReferenceException` when currency parameter is null.
- Chinese decimal path uses thread culture for `ToString()`, producing locale-dependent results.
- `CurrencyNegativePattern` 16 (`$- n`) missing from the pattern lookup table — causes `KeyNotFoundException` on locales that use this pattern.
